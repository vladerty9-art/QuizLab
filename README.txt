QuizLab — мобильный веб-тренажёр ОГЭ

Файлы:
- index.html — приложение
- manifest.webmanifest — параметры установки
- sw.js — кеширование для офлайн-открытия
- icon.svg — иконка

Публикация:
1. Загрузите содержимое этой папки в корневую папку сайта на хостинге.
2. Главный файл должен называться index.html.
3. Откройте адрес сайта на телефоне.
4. На iPhone: Safari → Поделиться → На экран «Домой».
   На Android: меню браузера → Установить приложение / Добавить на главный экран.

Важно:
Это первая автономная версия-прототип. Попытки и статистика хранятся локально в браузере на конкретном устройстве.
Каталог содержит 40 тематических направлений, сейчас полностью доступны 4 демонстрационных квиза по 5 вопросов. Остальные темы отмечены «Скоро».
Для общих аккаунтов, синхронизации между устройствами и единой базы учеников потребуется серверная база данных и авторизация.
